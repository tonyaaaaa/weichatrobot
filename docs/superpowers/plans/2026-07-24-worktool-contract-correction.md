# WorkTool Contract Correction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every implemented WorkTool path, request, response, callback, command status, group identity, script, and acceptance claim match documented WorkTool behavior.

**Architecture:** Replace the generic WorkTool success result with endpoint-specific typed contracts. Persist command receipts and update final execution state only from authenticated WorkTool result callbacks; keep local security, queues, confirmation, and audit behavior in application services rather than the HTTP client.

**Tech Stack:** .NET 10, ASP.NET Core Minimal APIs, EF Core/MySQL, `System.Text.Json`, xUnit v3/Microsoft Testing Platform, Vue 3, TypeScript, Element Plus, Vitest.

## Global Constraints

- Work in `H:\Codex\WechatRobot\.worktrees\codex-wechatrobot-mvp` on `codex/wechatrobot-mvp`.
- The approved specification is `docs/superpowers/specs/2026-07-24-worktool-contract-and-frontend-backend-alignment-design.md`.
- WorkTool documentation is authoritative for external paths, request fields, response codes, and callback fields.
- Do not implement undocumented group-remark mutation or group-template fields.
- Do not expose plaintext robot IDs or callback secrets in APIs, logs, audits, exceptions, snapshots, or Git.
- WorkTool HTTP acceptance is `accepted`, not final execution success.
- Do not automatically retry a group mutation after dispatch may have occurred.
- Preserve the current message callback three-second persistence boundary.
- Human-handoff member mapping and handoff pause-policy UI remain out of scope.
- Normal tests use fake HTTP handlers and local test databases only.
- Use `apply_patch` for hand-authored edits and EF tooling only for generated migrations.

```csharp
private static WorkToolCommandSubmission ToSubmission(
    HttpResponseMessage response,
    Envelope<string>? envelope,
    bool bodyParsed)
{
    if (!response.IsSuccessStatusCode)
        return new(false, null, $"worktool_http_{(int)response.StatusCode}", true);
    if (!bodyParsed || envelope is null)
        return new(false, null, "worktool_invalid_response", true);
    if (envelope.Code != 0)
        return new(false, null, $"worktool_code_{envelope.Code}", false);
    if (string.IsNullOrWhiteSpace(envelope.Data))
        return new(false, null, "worktool_message_id_missing", true);
    return new(true, envelope.Data.Trim(), null, false);
}
```

```csharp
public sealed record GeneratedCallbackCredential(

private GeneratedCallbackCredential Generate()
{
    var plaintext = WebEncoders.Base64UrlEncode(RandomNumberGenerator.GetBytes(32));
    var hash = Convert.ToHexString(SHA256.HashData(Encoding.UTF8.GetBytes(plaintext)));
    return new(plaintext, protector.Protect(plaintext), hash);
}
```

```csharp
public static bool Matches(
```
