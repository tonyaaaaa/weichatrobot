# 分段多选合并与只读状态设计

## 多段合并

- 允许选择两个或更多连续分段，一次原子合并。
- 请求使用 `previewIds`，后端按当前序号排序后验证连续性。
- 任意相邻项的页码、标题、表格元数据和 QA 语义不兼容时，整个请求失败，不产生部分修改。
- 重叠前缀按顺序逐段安全去重。
- 前端按钮显示 `合并所选（N）`，少于两个或选择不连续时禁用并说明原因。

## 只读状态

- `uploaded`、`preview` 允许生成和修改预览。
- `approved`、`indexing`、`indexed`、`active`、`disabled` 均只读。
- 页面读取当前版本的真实状态，不以索引状态推测。
- 只读时保留内容查看，禁用生成、编辑、拆分、选择、合并、删除和批准。
- 页面显示“当前版本已经批准，分段内容已锁定；如需修改，请上传新版本后重新分段”。

## 显示规则

- 内部 `sequence` 继续从 0 保存。
- 面向用户的段号统一显示 `sequence + 1`。
- 选择文案为“用于合并：选择第 N 段”。
