# 模型配置管理设计

## 背景

现有模型配置页面只能列出和编辑已存在的配置。后端通过
`PUT /api/admin/model-configurations/{name}` 按名称创建或更新配置，导致前端无法安全支持新增、
重命名和删除，也没有约束同类型默认配置、连接测试有效性或业务引用。

本设计补齐 OpenAI 兼容对话模型与向量模型的完整管理能力。系统仍为单企业、单租户，
只有管理员可以访问模型配置。

## 目标

- 支持新增、编辑、重命名和删除模型配置。
- 使用永久不变的数据库 ID 标识配置，名称仅作为可修改的显示与唯一检索字段。
- 对话模型和向量模型可各有多个配置，但每种类型最多一个默认配置。
- 只有通过当前配置连接测试的配置才允许启用或设为默认。
- 继续保证 API Key 加密存储，浏览器只能看到是否存在及末四位。
- 对默认配置和业务引用提供删除保护。
- 对所有管理变更保留不含敏感信息的审计记录。

## 非目标

- 不增加 OpenAI 兼容协议之外的供应商专有协议。
- 不实现租户级隔离或跨企业共享配置。
- 不允许业务侧直接读取明文 API Key。
- 不在本次功能中设计模型费用统计、Token 账单或智能路由。

## 领域模型

`ModelConfigEntity.Id` 是配置永久身份。任何重命名、修改地址或切换模型都不会改变 ID，
引用该配置的业务数据继续使用 ID 外键。

模型配置包含以下业务字段：

- `Name`：用户可读名称，去除前后空格后长度为 1–128 个字符。
- `NormalizedName`：用于不区分大小写的唯一约束。
- `Provider`：服务商显示名称，默认值为“OpenAI 兼容”。
- `ConfigurationType`：只允许 `chat` 或 `embedding`。
- `BaseUrl`：OpenAI 兼容接口根地址。
- `Model`：供应商模型名称。
- `EncryptedApiKey`：可空，加密保存。
- `TimeoutSeconds`：1–300。
- `MaxRetries`：0–5。
- `IsEnabled`：是否可被运行时选择。
- `IsDefault`：是否是同类型默认配置。
- `ConnectionStatus`：`Untested`、`Succeeded` 或 `Failed`。
- `LastTestedAtUtc`：最近一次测试完成时间。
- `LastTestFailureSummary`：脱敏后的失败摘要。
- `TestedConfigurationFingerprint`：成功测试所对应的配置指纹。
- `Version`：并发控制版本。

配置指纹覆盖类型、Base URL、模型名称和 API Key 版本。上述任一字段变化后，连接状态立即变为
`Untested`，清除测试时间、失败摘要和已测试指纹。指纹不得包含可逆的 API Key 数据。

## 业务规则

### 名称

- 名称允许修改。
- 名称按不区分大小写的规范化值唯一。
- 前后空格自动去除。
- 空名称和超过 128 个字符的名称拒绝保存。
- 名称冲突返回 `409 Conflict` 和可定位到名称字段的错误。

### 默认配置

- `chat` 和 `embedding` 各自最多一个默认配置。
- 将配置设为默认时，在同一数据库事务内取消同类型原默认项。
- 默认配置必须已启用，并且当前配置指纹对应最近一次成功测试。
- 停用默认配置前，必须先切换或清除同类型默认配置。

数据库约束与事务逻辑共同保证并发请求不会产生两个同类型默认项。

### 连接测试与启用

- 新建配置初始为停用和 `Untested`。
- 配置可以在未测试状态保存，但不能启用或设为默认。
- 测试成功后状态为 `Succeeded`；测试失败后状态为 `Failed` 并保存脱敏摘要。
- 修改类型、Base URL、模型名称或 API Key 后，测试状态失效。
- 连接测试使用配置的超时时间，并受到服务端最大超时保护。
- 浏览器请求断开不应留下错误的成功状态。

### API Key

- API Key 可选，以支持 Ollama、LM Studio、vLLM 等无需认证的 OpenAI 兼容服务。
- 编辑时 API Key 留空表示保留当前密钥。
- 清除密钥必须使用独立操作，避免空值语义歧义。
- 响应只返回 `HasApiKey` 和 `LastFour`，不返回明文或密文。
- 新增、更新、测试、清除和审计日志不得记录明文 API Key。

### 删除保护

- 默认配置不可直接删除。
- 被机器人、知识索引任务、会话或其他业务记录引用的配置不可直接删除。
- 删除冲突返回引用类型与数量，不返回不必要的业务内容。
- 无引用且非默认的配置可以经二次确认后删除。

## API 设计

管理员接口统一位于 `/api/admin/model-configurations`：

```text
GET    /api/admin/model-configurations
POST   /api/admin/model-configurations
PUT    /api/admin/model-configurations/{id}
DELETE /api/admin/model-configurations/{id}
POST   /api/admin/model-configurations/{id}/test-connection
DELETE /api/admin/model-configurations/{id}/api-key
```

创建接口接收名称、类型、服务商、地址、模型、可选 API Key、超时和重试参数。创建结果始终为停用且
未测试，避免未验证配置立即进入运行时。

更新接口按 ID 寻址，支持名称修改。请求携带并发版本；版本过期时返回 `409 Conflict`，
前端提示刷新后重试。

连接测试接口按 ID 读取服务端保存的完整配置，不接受浏览器回传密钥。成功或失败状态由服务端持久化。

清除密钥接口清空密文并使测试状态失效。

旧的 `PUT /{name}` 和 `POST /{name}/test-connection` 在迁移期保留兼容，但标记为废弃。
当前 Vue 后台切换到 ID 接口并完成回归验证后，再单独删除旧接口。

## 前端设计

模型配置页使用 Element Plus 实现“摘要卡片 + 新增/编辑弹窗”。

页面头部包含：

- “新增模型配置”主按钮。
- “刷新”按钮。
- 对话模型和向量模型分组。

每张配置卡片展示：

- 名称、类型和服务商。
- Base URL 与模型名称。
- 启用、默认和连接测试状态。
- API Key 是否存在及末四位。
- 编辑、测试连接、设为默认、启停和删除操作。

新增与编辑共用弹窗，包含：

- 配置名称。
- 配置类型。
- 服务商名称。
- Base URL。
- 模型名称。
- API Key。
- 超时时间。
- 最大重试次数。

编辑时 API Key 输入框默认留空，并说明“留空保留现有密钥”。已有密钥时显示独立的
“清除密钥”危险操作。

保存关键连接字段后，卡片显示“待测试”。只有 `Succeeded` 状态下才允许启用或设为默认。
删除使用二次确认；保护冲突展示明确原因，例如“该配置是默认对话模型，请先切换默认配置”。

## 数据流

### 新增并启用

1. 管理员打开新增弹窗并填写配置。
2. 前端执行客户端字段校验。
3. `POST` 创建停用、未测试配置。
4. 管理员点击“测试连接”。
5. 后端读取解密后的保存配置并调用对应客户端。
6. 测试成功后持久化状态和配置指纹。
7. 管理员启用配置；如需设为默认，后端在事务内切换同类型默认项。

### 编辑与重命名

1. 前端按 ID 提交修改和并发版本。
2. 后端规范化并校验名称。
3. 如果关键连接字段变化，测试状态失效。
4. ID 和所有外键引用保持不变。
5. 前端以响应中的最新版本和状态替换卡片数据。

### 删除

1. 管理员确认删除。
2. 后端检查默认状态和引用计数。
3. 有保护条件时返回结构化冲突。
4. 无保护条件时删除配置并记录审计。

## 错误处理

- 字段错误返回 `400 ValidationProblem`，字段键与表单字段对应。
- 名称冲突、并发冲突、默认冲突和删除保护返回 `409 Conflict`，使用稳定错误代码。
- 配置不存在返回 `404 Not Found`。
- 供应商连接失败返回业务失败结果并持久化 `Failed`，不泄露密钥、供应商响应正文或内部堆栈。
- 意外服务端错误返回统一 Problem Details，并在服务端使用关联 ID 记录日志。
- 前端保留用户已填写内容，字段错误就地展示，系统错误使用页面提示且允许重试。

## 审计

以下动作写入管理审计日志：

- 创建配置。
- 修改字段或重命名。
- 测试连接成功或失败。
- 启用或停用。
- 设置或切换默认。
- 更新或清除 API Key。
- 删除配置。

审计记录包含操作者、配置 ID、配置名称、动作、时间、结果和脱敏变更摘要。API Key 只记录
“已设置”“已替换”或“已清除”，不得记录明文、密文或末四位以外的信息。

## 测试策略

### 后端集成测试

- 创建配置并验证初始停用、未测试状态。
- 重命名保持 ID 不变。
- 名称规范化和不区分大小写冲突。
- 同类型默认切换及并发唯一性。
- 未测试配置不能启用或设为默认。
- 关键字段或密钥变化使测试状态失效。
- API Key 留空保留与独立清除。
- 默认配置和已引用配置的删除保护。
- 审计记录不含敏感信息。
- 旧按名称接口在兼容期继续工作。

### 前端组件测试

- 空状态显示新增入口。
- 新增和编辑弹窗字段回填与校验。
- API Key 留空说明和清除确认。
- 连接状态标签与启用、默认操作禁用条件。
- 后端字段错误、冲突和删除保护提示。
- 保存后按 ID 更新卡片，重命名不产生重复项。

### 端到端测试

覆盖完整路径：

1. 新增停用配置。
2. 测试连接成功。
3. 启用并设为同类型默认。
4. 重命名并确认 ID 不变。
5. 验证列表、刷新和重新登录后状态一致。

## 迁移与兼容

数据库迁移增加规范化名称、连接状态、测试时间、失败摘要、测试指纹和并发版本。
现有数据迁移为：

- 根据当前名称生成规范化名称。
- 连接状态设为 `Untested`。
- 已启用或默认的旧配置保留运行状态，但下一次关键字段修改后必须重新测试。
- 如现有数据存在同类型多个默认项，迁移前检查并阻止自动选择，要求管理员明确保留项。

前端切换到 ID 接口后，旧按名称接口进入废弃期。删除旧接口应作为后续独立兼容性变更，
不得与本次首次上线捆绑。

## 验收标准

- 空列表页面可以直接新增模型配置。
- 配置名称可以修改，ID 始终不变。
- 名称不区分大小写唯一。
- 对话和向量配置各自最多一个默认项。
- 未通过当前配置连接测试时不能启用或设为默认。
- API Key 可选、加密保存、可独立清除且不会返回浏览器。
- 默认项和已引用项不能直接删除。
- 所有管理操作有不含敏感信息的审计记录。
- 后端、前端组件和端到端测试覆盖主要成功与失败路径。
