# WorkTool 缺失群备注时的群身份匹配设计

## 问题

真实 WorkTool 消息回调可能只包含群名称而不包含 `groupRemark`。当前系统把本地非空
`WorkToolGroupRemark` 当作必需匹配条件，导致机器人、群名称均正确且候选唯一时仍返回
`group_rule_unmatched`。

## 已批准规则

1. 仅在同一机器人、启用群范围内按回调群名称查找候选。
2. 回调提供群备注时，优先使用备注完全相同的候选；没有精确候选时，才允许使用未配置备注的候选。
3. 回调不提供群备注时，群名称候选唯一即可确认身份。
4. 任一匹配层级存在多个候选时返回 `group_identity_ambiguous`，不得任意选择。
5. 找不到名称身份后，继续沿用包含、正则和排除规则；备注过滤采用相同优先级。
6. 不使用废弃的 `ExternalGroupId` 作为回调身份。

## 验证

- 唯一同名群配置了备注、回调未提供备注时能够继续处理。
- 同名群多个且回调未提供备注时拒绝为歧义。
- 回调提供备注时，精确备注优先于未配置备注的兜底项。
- 原有群规则、知识检索和发送链路测试保持通过。
