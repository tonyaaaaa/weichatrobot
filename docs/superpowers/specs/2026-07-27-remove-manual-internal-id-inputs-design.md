# 前端移除内部 ID 手工输入设计

## 目标

后台用户通过名称、状态和业务上下文选择真实实体，前端自动提交内部 ID。
任何已有可靠数据源的内部 UUID 都不得要求用户复制或手工输入。

## 范围

### 会话审计

- 将“群 ID”文本框替换为可搜索、可清空的群选择器。
- 显示群名称、WorkTool 群备注、机器人名称和启停状态。
- 选择值仍为 `GroupProfile.Id`，查询参数仍使用 `groupId`。
- 提供与会话审计相同权限范围的只读群选项接口，避免
  `KnowledgeOperator` 依赖仅限 `Admin` 的群管理接口。
- 包含停用群，使历史审计仍可查询。

### 群操作

- “登记已有群”和“新建或调整群”中的机器人配置 ID 文本框都替换为
  机器人选择器。
- 复用现有 `/api/admin/worktool/robots` 数据源。
- 显示机器人名称和启停状态，提交值为内部 `RobotConfig.Id`。
- 登记和执行只允许选择启用机器人；没有可用机器人时显示明确空状态。
- 选择已登记群时继续自动带入该群关联的机器人配置和群标识。

### 人工转接

- 将“客服用户 ID”替换为可搜索客服选择器。
- 新增 `/api/handoffs/assignees` 只读接口，与人工转接页面使用相同权限。
- 只返回启用且拥有 `HumanAgent` 或 `Admin` 角色的后台用户。
- 显示名称、邮箱和角色，提交值为 `ApplicationUser.Id`。
- 已分配但后来停用的用户仍在详情中显示为历史选中项，但不能重新选择。

### 管理审计

- “操作人”“动作”“目标类型”改为可清空选择器。
- “目标 ID”改为依赖目标类型的远程可搜索选择器，不要求输入完整 ID。
- 选项来自管理审计记录本身，而不是只查询当前业务表，因此已删除对象仍可筛选。
- 后端提供有界、去重的筛选选项查询；目标搜索最多返回 50 条，避免无界加载历史数据。
- 目标选项优先显示审计记录中可安全读取的名称；没有名称时显示目标类型和缩略 ID，
  但用户不需要手工输入 ID。

## 保留输入的标识

以下值不是系统内部实体 ID，不纳入替换：

- WorkTool 机器人 ID：外部平台凭据，只允许写入或轮换。
- WorkTool 群名称、群备注和成员显示名：外部命令按显示文本执行。
- 路由参数、只读详情和审计结果中展示的 ID：不是用户输入控件。

## API 与权限

- 选择项接口只返回完成选择所需的最小字段，不返回密钥、令牌或认证信息。
- 会话审计群选项使用 `KnowledgeOperator` 权限。
- 人工转接客服选项使用 `HumanAgent` 权限。
- 群操作机器人选项和管理审计选项继续使用 `Admin` 权限。
- 后端仍校验提交的 ID、启用状态和角色；下拉选择不替代服务端授权和验证。

## 前端交互

- 使用 Element Plus 可搜索、可清空选择器，并保持可见标签和键盘操作。
- 加载中禁用提交操作，加载失败显示就近错误和重试入口。
- 空列表明确说明应先去哪个管理页面创建或启用数据。
- 选择器显示业务名称，必要时附加状态或邮箱；不把裸 UUID 作为主要文案。
- 页面 API 继续提交原有字段名，避免无关的业务契约改名。

## 测试

- 前端组件测试覆盖选项加载、名称展示、选择后提交真实 ID、空状态和加载失败。
- API 客户端测试覆盖新增选择项接口及查询参数。
- 后端集成测试覆盖角色授权、最小响应字段、停用实体处理和历史审计目标查询。
- 现有群操作、会话审计、人工转接和管理审计测试继续通过。
- 最终运行前端单测、类型检查、构建以及相关后端测试，并在本地页面验证不再存在内部
  ID 手工输入控件。

## 非目标

- 不改变内部主键、数据库外键或现有业务写入请求结构。
- 不把 WorkTool 显示名误当作稳定成员 ID。
- 不新增通用的全局 `/api/options` 聚合接口。
- 不修改外部平台凭据的录入和轮换方式。
